Free · Open source · Chrome extension

Never forget where you applied.

A Chrome extension that records each job application as you submit it on LinkedIn, Indeed, GitHub job lists, Greenhouse, Lever and more, plus a dashboard to track status, interviews and resumes. All data stays on your device.

▶ Try the live dashboard ⬇ Download the extension

The live demo opens with sample data (fictional companies). Anything you add is saved only in your browser.

Install in 3 steps

No Chrome Web Store account needed. Takes about a minute.

Download and unzip

Download the zip (also on GitHub Releases) and unzip it to a folder you will keep.

Enable Developer mode

Open chrome://extensions in Chrome and switch on Developer mode (top-right).

Load unpacked

Click Load unpacked, select the unzipped folder, and pin the extension. The dashboard opens automatically.

What you get

Everything below is in the code today.

🤖Auto-tracking

Detects application submits and "Apply" clicks, grabs company, role, location and URL, skips duplicates within 7 days.

📊Dashboard

Stats, recent activity, a 14-day timeline, search (⌘K), filters, sorting and one-click status changes.

📅Interview calendar

Add an interview date to any application and see upcoming and past interviews in order.

📄Resume vault

Keep each resume version in the browser (IndexedDB). Nothing is uploaded.

📈Analytics

Status breakdown, applications per week, sources and a response funnel, drawn with Chart.js.

🔒Private by design

No server, no account, no analytics. Export everything to CSV whenever you want.
