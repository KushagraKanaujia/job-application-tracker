# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Job Application Tracker, please report it by emailing the maintainers. Please do NOT open a public issue.

## What to Include

When reporting a vulnerability, please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

## Response Time

We will respond to security reports within 48 hours and provide a fix within 2 weeks for critical issues.

## Scope

This security policy applies to:

- The Chrome extension code
- The web dashboard
- Data storage mechanisms

## What We Do

- All data is stored locally (no cloud storage)
- No external API calls or tracking
- Extension runs only on job sites (limited permissions)
- Open source and auditable code

## What We Don't Do

- We don't collect any user data
- We don't send data to external servers
- We don't use analytics or telemetry
- We don't store passwords or credentials

## Known Limitations

- Extension requires broad permissions for job sites
- Data is stored unencrypted in browser storage
- No authentication system (local only)

If you have concerns about these, please open a discussion.
