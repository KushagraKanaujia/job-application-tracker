# Frequently Asked Questions

## Installation

### How do I install the extension?
See [EXTENSION_INSTALL.md](../EXTENSION_INSTALL.md) for detailed instructions.

### Does this work on Firefox?
Not yet. Chrome only for now. Firefox support is planned for a future release.

### Can I use this on mobile?
The extension is desktop Chrome only. Mobile app is on the roadmap.

## Usage

### Which platforms are supported?
- LinkedIn, GitHub, Indeed, Glassdoor
- ZipRecruiter, Dice
- Greenhouse, Lever, Workable, SmartRecruiters (ATS)
- And more being added regularly

### The extension didn't detect my application. What do I do?
Use the manual add feature in the extension popup. Also, please report which site it was so we can add support.

### Can I edit applications after they're tracked?
Yes! Click the edit icon (✏️) on any application in the dashboard.

## Privacy

### Where is my data stored?
All data is stored locally on your machine in Chrome's storage. Nothing goes to external servers.

### Can others see my applications?
No. Everything is local to your browser. Your data never leaves your machine.

### Do you track me?
No tracking, no analytics, no telemetry. The extension only runs on job sites when you're applying.

## Technical

### Why does the extension need so many permissions?
We need access to job sites to detect applications. Each site requires explicit permission.

### Will this slow down my browser?
No. The extension is lightweight and only activates on job sites.

### How do I backup my data?
Use the "Export to CSV" feature regularly. Your data is also in Chrome's local storage.
