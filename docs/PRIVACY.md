# Privacy Policy

## Data Collection

**We collect ZERO data.** This extension does not collect, transmit, or share any of your personal information.

## Local Storage Only

All job application data is stored locally on your machine using:
- Chrome's local storage API (for the extension)
- Browser localStorage (for the web dashboard)

Your data never leaves your computer.

## No External Servers

This extension does not:
- Send data to external servers
- Make API calls to third parties
- Use analytics or tracking services
- Transmit your information anywhere

## Permissions Explained

The extension requests these permissions:

- **storage**: To save your applications locally
- **tabs**: To detect which job site you're on
- **notifications**: To show when an application is tracked
- **host_permissions**: To run on job sites (LinkedIn, GitHub, etc.)

We only use these permissions for the stated functionality. Nothing more.

## Open Source

All code is open source and auditable. You can review exactly what the extension does:

- [Extension Source Code](../chrome-extension/)
- [Dashboard Source Code](../app.js)

## Your Control

You have complete control over your data:

- Export to CSV anytime
- Delete applications whenever you want
- Uninstall the extension to remove all data
- Your data stays on your machine

## Changes to Privacy Policy

Any changes to this policy will be documented in the CHANGELOG and committed to the repository.

## Questions?

If you have privacy concerns, please open an issue on GitHub.
